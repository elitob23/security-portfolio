# Requirements for ipautoscan.py
#

#
# Third-party packages:

#

#   ipaddress, json, os, threading, tkinter
#

#   sudo apt install python3-tk
#
# Also required, but not a package:

#
# Install with:
#   pip install -r requirements.txt
